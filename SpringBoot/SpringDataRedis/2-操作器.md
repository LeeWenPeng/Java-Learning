在 Spring Data Redis 中，为每一个 Redis 数据类型都提供了对应的操作器，名称为 `opsForxxx()`

| 方法名                       | 对应 Redis 数据结构         | 核心命令示例                                  | 典型使用场景                                                                    |
| ------------------------- | --------------------- | --------------------------------------- | ------------------------------------------------------------------------- |
| **`opsForValue()`**       | **String（字符串）**       | `SET`, `GET`, `INCR`, `SETNX`           | **最常用**。缓存对象（JSON 字符串）、分布式 ID 生成、计数器（如你之前的 `increment`）、分布式锁。             |
| **`opsForHash()`**        | **Hash（散列表）**         | `HSET`, `HGET`, `HINCRBY`, `HGETALL`    | 存储对象的部分属性（如用户信息）、购物车数据（field=商品 ID, value=数量）。适合频繁修改个别字段的场景。              |
| **`opsForList()`**        | **List（列表）**          | `LPUSH`, `RPUSH`, `LPOP`, `LRANGE`      | 消息队列（生产者 - 消费者）、最新消息/动态时间线（如微博最新 10 条）、栈和队列结构。                            |
| **`opsForSet()`**         | **Set（无序集合）**         | `SADD`, `SREM`, `SISMEMBER`, `SINTER`   | 去重标签（用户标签）、共同好友（交集）、抽奖随机数（`SRANDMEMBER`）。                                 |
| **`opsForZSet()`**        | **Sorted Set（有序集合）**  | `ZADD`, `ZRANK`, `ZREVRANGE`, `ZINCRBY` | **排行榜**（游戏积分榜、热搜榜单）、延迟队列（按时间戳排序）、带权重的消息队列。                                |
| **`opsForGeo()`**         | **Geo（地理位置）**         | `GEOADD`, `GEORADIUS`, `GEODIST`        | 附近的人、共享单车定位、外卖配送范围计算。                                                     |
| **`opsForHyperLogLog()`** | **HyperLogLog（基数统计）** | `PFADD`, `PFCOUNT`, `PFMERGE`           | 海量数据的 UV 统计（独立访客数）。优点：占用内存极小（12KB），但存在约 0.81% 的标准误差。                      |
| **`opsForStream()`**      | **Stream（流）**         | `XADD`, `XREAD`, `XGROUP`, `XACK`       | **Redis 5.0 引入的持久化消息队列**。相比 List，支持消费者组、消息回溯、ACK 确认，功能类似 Kafka（轻量级消息中间件）。 |
