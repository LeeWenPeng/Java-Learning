## 1  RedisTemplate

`RedisTemplate<K, V>` 是一个通用泛型类。

> [!note]
> 使用时一定要自定义序列化器。

常用实践

- 将 key 的序列化器设为 `StringRedisSerializer`
- 将 value 的序列化器设为 `Jackson2JsonRedisSerializer`
- 既保证了 key 的可读性，又方便存取 JSON 格式的对象

## 2  StringRedisTemplate

StringRedisTemplate 是 RedisTemplate 的一个特化子类，专门用于处理 key 和 value 都是 String 的场景

## 3  RedisTemlate VS. StringRedisTemplate

| 特性                | `RedisTemplate` (默认)                                                                      | `StringRedisTemplate`                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **默认序列化器**        | `JdkSerializationRedisSerializer`                                                         | `StringRedisSerializer`                                                                     |
| **存储格式**          | **二进制字节数组**，包含类结构信息，不可读 [](https://blog.csdn.net/ze15829163918/article/details/150337852) | **纯字符串**，在 Redis 客户端中直接可读 [](https://blog.csdn.net/ze15829163918/article/details/150337852) |
| **redis-cli 可读性** | ❌ 差，显示为乱码 [](https://blog.csdn.net/qq_46548855/article/details/156200798)                 | ✅ 好，直接显示文本 [](https://blog.csdn.net/qq_46548855/article/details/156200798)                  |
| **跨语言兼容性**        | ❌ 差，仅 Java 能解析 [](https://blog.csdn.net/weixin_29297127/article/details/159335914)        | ✅ 好，任何语言都能处理 [](https://blog.csdn.net/qq_46548855/article/details/156200798)                |

## 4  选型

- `StringRedisTemplate`：安全默认值
	- 适合场景
		- Lua 脚本
		- 分布式锁
		- 限流器
		- 计数器
	- 理由
		- Lua 只认字符串
		- 简单、直接、稳定
		- 不需要对象反序列化
- `RedisTemplate`：需要配置的高级工具
	- 适合场景
		- 缓存对象（DTO/VO/配置）
	- 理由
		- 自动序列化/反序列化
		- JSON 可读、可维护
		- 跨语言兼容

结论：在同一个项目内，推荐混合使用。

- 对于简单的只需要 String 的场景，使用 `StringRedisTemplate`
- 对于需要存储复杂对象的场景，使用 `RedisTemplate`
- 能用 `StringRedisTemplate` ，就优先使用

## 5  陷阱

由于，`RedisTemplate` 和 `StringRedisTemplate` 的序列化器不同。所以，默认情况下，二者无法读取由对方写入的数据。

### 5.1  解决方案

- 统一模板：在项目中尽可能统一使用 `StringRedisTemplate`
- 统一序列器：在混用的情况下，确保所有模板的 key 序列化器都是 `StringRedisSerializer`
