## 1  模板相关接口

### 1.1  创建模板

```bash
POST msg/create_template
```

#### 1.1.1  请求字段

| 字段         | 类型       | 描述              |
| ---------- | -------- | --------------- |
| `name`     | `string` | 模板名称            |
| `content`  | `string` | 模板内容，支持占位符      |
| `channel`  | `int`    | 推送渠道。1: 邮件；2：短信 |
| `sourceID` | `string` | 创建模板的渠道 ID      |
| `subject`  | `string` | 消息主题            |
| `signName` | `string` | 签名，部分短信渠道需要     |

#### 1.1.2  返回字段

| 字段           | 类型       | 描述                  |
| ------------ | -------- | ------------------- |
| `code`       | `int`    | 返回编码。0：成功           |
| `message`    | `string` | 返回信息                |
| `data`       | `struct` | 返回的数据，以下行都是 data 中的字段 |
| `templateID` | `string` | 模板 ID               |

#### 1.1.3  JSON 示例

```json
// 请求包
{
	"name": "订单通知",
	"content": "亲爱的 {{.username}}，您的订单 {{.order_id}} 已经发货。",
	"sourceID": "xxxx",
	"channel": 1,
	"subject": "订单发货了"
}

// 返回包
{
	"code": 0,
	"message": "success",
	"data":{
		"templateID": "xxxxx"
	}
}
```

### 1.3  更新模板

```bash

```

#### 1.3.1  请求字段

| ------------ | -------- | ----------------------- |
| `templateID` | `string` | 模板 ID                   |

| `content`    | `string` | 模板内容，支持占位符。不填则不更新       |
| `channel`    | `int`    | 推送渠道。1: 邮件；2: 短信。不填则不更新 |
| `sourceID`   | `string` | 创建模板的渠道 ID              |
| `subject`    | `string` | 消息主题                    |

#### 1.3.2  返回字段

| 字段        | 类型       | 描述                    |
| --------- | -------- | --------------------- |
| `code`    | `int`    | 返回代码。0: 成功            |
| `message` | `string` | 返回信息                  |
| `data`    | `struct` | 返回的数据，以下行都是 data 中的字段 |

#### 1.3.3  JSON 示例

```json
// 请求包
{
	"templateID": "xxx",
	"name": "订单通知",

{
	"code": 0,
```

## 2  推送消息相关接口

### 2.1  推送消息

```bash
POST msg/send_msg
```

#### 2.1.1  请求字段

| 字段              | 类型       | 描述               |
| --------------- | -------- | ---------------- |
| `to`            | `string` | 消息接受者            |
| `subject`       | `string` | 消息主题             |
| `priority`      | `int`    | 优先级              |
| `templateID`    | `string` | 模板 ID            |
| `templateData`  | `map`    | 传入模板的 Data       |
| `sendTimestamp` | `int64`  | 发送时间戳， 秒级。定时消息填入 |

#### 2.1.2  返回字段

| 字段        | 类型       | 描述         |
| --------- | -------- | ---------- |
| `code`    | `int`    | 返回代码。0: 成功 |
| `message` | `string` | 返回信息       |
| `msgID`   | `string` | 消息 ID      |

#### 2.1.3  JSON 示例

```json
// 请求包
{
	"to": "xxx",
	"sourceID": "xxx",
	"subject": "发货通知",
	// templateID 对应的模板内容为
	// "亲爱的 {{.username}}，您的订单 {{.order_id}} 已经发货。"
	"templateID": "xxx",
	"templateData": {
		"user_name": "张三",
		"order_id": "xxx"
	}
}

// 返回包
{
	"code": 0,
	"message": "success",
	"msgID": "xxxx"
}
```

### 2.2  查询消息发送的记录

```bash
GET msg/get_msg_record
```

#### 2.2.1  请求字段

| 字段        | 类型       | 描述         |
| --------- | -------- | ---------- |
| `msgID`   | `string` | 消息 ID      |

#### 2.2.2  返回字段

| 字段             | 类型       | 描述                    |
| -------------- | -------- | --------------------- |
| `code`         | `int`    | 返回代码。0: 成功            |
| `message`      | `string` | 返回信息                  |
| `to`           | `string` | 消息接受者                 |
| `subject`      | `string` | 消息主题                  |
| `templateID`   | `string` | 模板 ID                 |
| `templateData` | `map`    | 传入模板的 Data            |
| `status`       | `int`    | 消息状态。1: 等待中；2: 成功；3: 失败 |

#### 2.2.3  JSON 示例

```json
// 请求包
{
	"msgID": "xxx"
}

// 返回包
{
	"code": 0,
	"message": "success",
	"to": "xxx",
	"subject": "测试消息",
	"templateID": "xxx",
	"templateData": {
		"user_name": "张三",
		"order_id": "xxx"
	},
	"status": 1
}
```
