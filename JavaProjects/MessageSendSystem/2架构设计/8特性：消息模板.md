## 1  消息模板的作用

消息模板主要提供以下功能

1. 抽象内容信息。模板中支持插入动态数据（例如 `{{username}}`），也就是支持动态替换占位符生成完整的消息内容。
2. 抽象渠道信息。比如，支持短信、邮件、飞书等。
3. 提供模板管理能力。消息模板提供模板的创建、修改、删除和查询功能。

## 2  数据库设计

### 2.1  模板表 t_msg_template

| 字段                | 类型              | 描述                      |
| ----------------- | --------------- | ----------------------- |
| `id`              | `bigint`        | 模板唯一标识                  |
| `template_id`     | `varchar(256)`  | 模板 ID                   |
| `rel_template_id` | `varchar(256)`  | 关联模板 ID，该字段用于支持第三方平台模板。 |
| `name`            | `varchar(256)`  | 模板名称                    |
| `content`         | `varchar(4096)` | 模板内容，支持占位符              |
| `source_id`       | `varchar(256)`  | 业务 ID                   |
| `sign_name`       | `varchar(50)`   | 签名，短信渠道需要               |
| `subject`         | `varchar(256)`  | 消息主题                    |
| `channel`         | `int(10)`       | 消息类型。1：邮件；2: 短信；3: 飞书   |
| `status`          | `tinyint(3)`    | 消息状态                    |
| `ext`             | `varchar(256)`  | 扩展字段，保留                 |
| `create_time`     | `datetime`      | 创建时间                    |
| `modify_time`     | `datetime`      | 修改时间                    |

> [!note]
> 针对该表，服务层要提供增删改查接口。

### 2.2  RESTful 接口设计

- 创建模板：`POST /api/templetes
- 获取模板：`GET /api/templetes/{id}`
- 更新模板：`POST /api/templetes/{id}`
- 删除模板：`DELETE /api/templetes/{id}`

#### 2.2.1  示例——创建模板的请求包


## 3  Java 模板

### 3.1  FreeMarker 是什么？

Java 可以使用 FreeMarker 实现动态模板渲染。FreeMarker 是一个基于 Java 的模板引擎（Template Engine）。它能够将**预定义的模板**和**动态数据**相结合，最终生成你想要的**文本输出**。

### 3.2  示例

使用 FreeMarker 支持模板

- `亲爱的 ${username}，您的订单 ${orderId} 已发货!`

```xml
<!-- Source: https://mvnrepository.com/artifact/org.freemarker/freemarker -->
<dependency>
    <groupId>org.freemarker</groupId>
    <artifactId>freemarker</artifactId>
    <version>2.3.34</version>
    <scope>compile</scope>
</dependency>
```

```Java
package Object.AliyunTest;

import freemarker.template.Configuration;
import freemarker.template.Template;

import java.io.StringWriter;
import java.util.HashMap;
import java.util.Map;

/**
 * @BelongsProject: 消息推送系统
 * @BelongsPackage: Object.AliyunTest
 * @Author: Lee
 * @CreateTime: 2026-07-09 00:01
 * @Description: 测试 freemarker 模板渲染
 * @Version: 1.0
 */
public class TemplateRender {
    public static String renderTemplate(String templateContent, Map<String, Object> data) throws Exception {
        // 创建 Configuration 实例
        Configuration cfg = new Configuration(Configuration.VERSION_2_3_34);
        // 开启经典兼容模式，除非使用需要兼容旧模板，否则保持默认的false更加安全明确
        cfg.setClassicCompatible(true);
        // 创建 Template 对象
        // 参数：
        //  - "template"：模板名称，用于调试和错误信息；
        //  - templateContent：模板的字符串内容
        //  - cfg：配置对象
        Template template = new Template("template", templateContent, cfg);
        // 创建输出 writer
        StringWriter writer = new  StringWriter(); // 底层是一个 StringBuffer
        // 执行渲染，将data填充到模板中，并将结果写入 writer
        template.process(data, writer);
        return writer.toString();
    }

    public static void main(String[] args) {
        try{
            String templateContent = "亲爱的 ${username}，您的订单 ${orderId} 已发货!";
            Map<String, Object> data = new HashMap<String, Object>();
            data.put("username", "admin");
            data.put("orderId", "1");
            String res = renderTemplate(templateContent, data);
            System.out.println(res);
        }catch(Exception e){
            e.printStackTrace();
        }
    }
}
```
