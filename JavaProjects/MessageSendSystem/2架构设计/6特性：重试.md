## 1  前言

失败总是不可避免的，比如网络波动、机器重启等情况。因此，可以通过重试功能来提高消息推送成功率。

## 2  快速重试

### 2.1  思路

当一次推送失败时，**快速进行 3 次左右的重试**。这种机制能够有效应对**网络波动**的情况，

### 2.2  示例

```java
package Object.AliyunTest;

import java.util.Random;

/**
 * @BelongsProject: 消息推送系统
 * @BelongsPackage: Object.AliyunTest
 * @Author: Lee
 * @CreateTime: 2026-07-07 13:01
 * @Description: 快速重试，当推送失败时，快速发送三次
 * @Version: 1.0
 */
public class RetryExample {
    private static final int MAX_RETRIES = 3;

    public static void main(String[] args) {
        boolean success = sendMessageWithRetry("Test Message");
        if(success){
            System.out.println("消息发送成功！");
        }else{
            System.out.println("重试后消息仍然发送失败");
        }
    }

    /**
     * 快速重试，通过一个 while 循环控制重试次数，捕捉到异常后，再次重试，每次重试后都等待一段时间
     * @param message
     * @return
     */
    public static boolean sendMessageWithRetry(String message){
        int attempts = 0; // 记录当前尝试次数
        while (attempts < MAX_RETRIES){
            attempts++;
            try {
                sendMessage(message); // 发送消息
                return true;
            } catch (Exception e) {
	            // 捕捉到异常，进行重试
                System.out.println("Attempt " + attempts + " of " + MAX_RETRIES + " failed." + " failed:" + e.getMessage());
                if(attempts >= MAX_RETRIES){
                    System.out.println("已经达到最大的尝试次数，放弃重试！");
                    return false;
                }

                // 等待一段时间后再重试，防止过于频繁的请求
                try{
                    Thread.sleep(1000 * attempts); // 指数退避 1s 2s 3s
                }catch(InterruptedException ie){
                    Thread.currentThread().interrupt(); // 恢复中断状态
                }
            }
        }
        return false;
    }

    /**
     * 模拟消息发送
     * @param message
     * @throws Exception
     */
    public static void sendMessage(String message) throws Exception{
        System.out.println("Sending Message: " + message);
        if(new Random().nextInt(3) != 0){
            // 随机模拟失败 失败频率 2/3
            throw new Exception("Random failure occurred.");
        }
        System.out.println("Message sent successfully.");
    }
}
```

## 4  两种方案的结合

1. 当消息推送失败后，进行三次重试。
2. 如果三次重试都失败后，就将消息重新投递到队尾，或是单独的重试主题。
