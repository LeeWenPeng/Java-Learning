## 1 介绍

通过第三方平台 (阿里云短信服务) 来发送短信。

## 2 阿里云 SDK 申请

1. 登录阿里云控制台，并开通 [短信服务](https://www.aliyun.com/product/sms)
2. [阿里云短信服务-API参考](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2017-05-25-overview)
3. 获取 AccessKey ID 和 AccessKey Secret
4. 创建短信签名和模板

## 3 Java 示例

### 3.1 Maven 依赖

[阿里云 Maven 搜索](https://maven.aliyun.com/mvn/search)

<dependency>

### 3.2 Java

```java
import com.aliyuncs.CommonRequest;
import com.aliyuncs.CommonResponse;
import com.aliyuncs.DefaultAcsClient;
import com.aliyuncs.profile.DefaultProfile;

public class AliyunSmsDemo {
    public static void main(String[] args) {
        DefaultProfile profile = DefaultProfile.getProfile("cn-hangzhou",    // 地域ID
                "accessId",                                                         // 获取的 AccessKey ID
                "accessSecret");                                                    // 获取的 AccessKey Secret
        DefaultAcsClient client = new DefaultAcsClient(profile);
        // 构建请求
        CommonRequest request = getCommonRequest();
        try{
            // 发送请求并响应
            CommonResponse response = client.getCommonResponse(request);
            System.out.println(response.getData());
        }catch (Exception e){
            e.printStackTrace();
        }
    }

    private static CommonRequest getCommonRequest() {
        CommonRequest request = new CommonRequest();
        request.setSysMethod(com.aliyuncs.http.MethodType.POST);
        request.setSysDomain("dysmsapi.aliyuncs.com");
        request.setSysVersion("2017-05-25");
        request.setSysAction("SendSms");

        /* 设置参数 */
        request.putQueryParameter("PhoneNumbers", "1801231230");            // 接受短信的手机号
        request.putQueryParameter("SigName", "YourSigName");                // 短信签名
        request.putQueryParameter("TemplateCode", "SMS_123456789");         // 模板代码
        request.putQueryParameter("TemplateParam", "{\"code\":\"1234\"}");  // 模板参数
        return request;
    }
}
```
