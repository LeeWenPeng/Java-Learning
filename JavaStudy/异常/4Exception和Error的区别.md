## 1  Exception 和 Error 的区别？

- Exception 和 Error 是 JAVA 设计者对不同的异常情况的分类，二者都是继承自 Throwable 类。在 JAVA 中只有继承了 Throwable 类的实例才可以被捕获和抛出
- Error 是通常不可预料、不可处理的错误，这一类错误，往往是 JVM 层面的错误，是应用程序不需要捕获和处理的情况
- Exception 是程序正常运行中，出现的可以预料的意外情况，这类异常可以被捕获，也可以被处理
- Exception 也分为受检异常和非受检异常两类：
- 非受检异常，也叫运行时异常，一般是编写代码时就可以避免的逻辑错误。这类异常，在编译期并不强制要求检查。可以根据需求，判断是否需要进行捕获和处理
- 其中，受检异常是运行时异常之外的异常，如果方法中存在受检异常，则必须显式声明，并对捕获到的受检异常则必须处理或抛出。
