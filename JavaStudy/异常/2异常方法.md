## 1  方法

### 1.1  获取 message

返回异常的 message

```java
// 获取详细信息
String getMessage()

// 用本地语言表示的详细信息
String getLocalizedMessage()
```

### 1.2  返回对 Throwable 的简单描述

返回对 Throwable 的简单描述

```java
String toString()
```

### 1.3  打印调用栈轨迹

将当前异常的堆栈跟踪信息直接打印到标准错误流（System.err），也可以重定向到指定的 PrintStream 或 PrintWriter。

```java
void printStackTrace()
void printStackTrace(PrintStream)
void printStackTrace(java.io.PrintWriter)
```

- 第一种输出到标准错误 `err`
- 后两种允许选择要输出的流
- 返回结果包含 `toString()` 的结果

### 1.4  获取堆栈信息

返回一个 `StackTraceElement[]` 数组，每个元素代表栈中的一个调用帧（方法调用信息）。

```java
StackTraceElement[] getStackTrace()
```

- 返回值：`StackTraceElement[]`，可以遍历并获取类名、方法名、文件名、行号等信息。
- `printStackTrace()` 的实现依赖于 `getStackTrace()`：`Throwable.printStackTrace()` 内部会先调用 `getStackTrace()` 获得 `StackTraceElement[]` 数组，然后遍历这个数组，将每个元素的 `toString()` 结果打印到指定的输出流。

### 1.5  打印栈帧状态

用于在 Throwable 对象的内部记录栈帧的当前状态。

返回一个 Throwable 对象，它是通过把当前调用栈信息填入原来那个异常对象而建立。也就是说，以当前调用栈信息替代原始调用栈信息。

```java
Throwable fillInStackTrace()
```

### 1.6  继承自 Object 类的成员

```java
// 获取类对象
getClass()

// 获取类对象包含的包信息
getName()

// 获取类名
getSimpleName()
```
