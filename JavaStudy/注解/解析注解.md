## 1  概念

通过反射获取元素上的运行时注解信息，从而实现动态控制程序运行的逻辑

## 2  运行时注解反射 API

若注解的 `@Retention` 策略为 `RUNTIME`，则可通过 Java 反射机制在运行时获取注解信息并进行处理。

### 2.1  判断是否存在注解

```java
boolean isAnnotationPresent(Class<? extends Annotation> annotationClass)
```

- **参数**：目标注解的 `Class` 对象。
- **返回**：`true` 表示该元素在运行时存在指定注解；`false` 表示不存在（或注解生命周期非 `RUNTIME`）。

**适用对象**：`Class`、`Method`、`Field`、`Constructor`、`Parameter` 等反射类。

### 2.2  获取注解实例

```java
<T extends Annotation> T getAnnotation(Class<T> annotationClass)
```

- **返回**：指定类型的注解实例，若不存在则返回 `null`。

此外，还提供以下相关方法：

| 方法 | 说明 |
| :--- | :--- |
| `Annotation[] getAnnotations()` | 获取该元素上**所有**运行时可见的注解（包括继承的）。 |
| `Annotation[] getDeclaredAnnotations()` | 获取**直接修饰**该元素的所有运行时注解（不含继承）。 |
| `<T> T[] getAnnotationsByType(Class<T>)` | 获取指定类型的重复注解数组（Java 8+）。 |

### 2.3  读取注解元素值

获取到注解实例后，直接调用对应元素的方法即可获取配置值：

```java
Task task = obj.getClass().getAnnotation(Task.class);
if (task != null) {
    String desc = task.description();
    int prio = task.priority();
}
```

### 2.4  综合应用示例

```java
public class AnnotationProcessor {
    public static void process(Object obj) throws Exception {
        Class<?> clazz = obj.getClass();
        
        // 遍历所有方法
        for (Method method : clazz.getDeclaredMethods()) {
            RunImmediately anno = method.getAnnotation(RunImmediately.class);
            if (anno != null) {
                int times = anno.times();
                for (int i = 0; i < times; i++) {
                    method.invoke(obj);
                }
            }
        }
    }
}
```
