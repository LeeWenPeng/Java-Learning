## 1  注解概述

注解（Annotation）是 Java 5 引入的一种元数据机制，用于为代码元素（类、方法、字段、参数等）附加结构化信息。这些信息可以在编译期、类加载期或运行期被相应的处理器读取，从而实现配置简化、代码检查、框架自动化等功能。

与注释（Comment）不同，注解具有明确的类型定义和生命周期，能够被编译器或运行时环境识别并处理。

## 2  元注解（Meta-Annotations）

元注解是用于修饰其他注解定义的注解，Java 提供了四个标准元注解，其中最常用的是 `@Target` 和 `@Retention`。

### 2.1  作用域 `@Target`

`@Target` 用于限定自定义注解能够修饰哪些程序元素。若未显式指定，则默认允许修饰所有元素。

| 枚举常量 | 作用目标 |
| :--- | :--- |
| `ElementType.TYPE` | 类、接口（包括注解类型）、枚举声明 |
| `ElementType.FIELD` | 字段声明（包括枚举常量） |
| `ElementType.METHOD` | 方法声明 |
| `ElementType.PARAMETER` | 形参声明 |
| `ElementType.CONSTRUCTOR` | 构造方法声明 |
| `ElementType.LOCAL_VARIABLE` | 局部变量声明 |
| `ElementType.ANNOTATION_TYPE` | 注解类型声明 |
| `ElementType.PACKAGE` | 包声明 |
| `ElementType.TYPE_PARAMETER` | 类型参数声明（Java 8+） |
| `ElementType.TYPE_USE` | 任何类型使用位置（Java 8+） |

示例：

```java
// 限定该注解只能修饰方法
@Target(ElementType.METHOD)
public @interface MyMethodAnnotation { }

// 允许修饰类、接口、枚举和方法
@Target({ElementType.TYPE, ElementType.METHOD})
public @interface MyMultiTargetAnnotation { }
```

> 结合 `ElementType.TYPE_USE` 和 `ElementType.TYPE_PARAMETER`，注解可应用于任何类型使用位置（如泛型参数、`throws` 子句、强制类型转换等），为静态分析工具（如 Checker Framework）提供更细粒度的类型检查能力。

### 2.2  声明周期 `@Retention`

`@Retention` 定义注解的保留策略，即注解信息在哪个阶段有效。

| 策略常量 | 生命周期 | 说明 |
| :--- | :--- | :--- |
| `RetentionPolicy.SOURCE` | 仅保留在源代码中 | 编译时被丢弃，对 `.class` 文件不可见。常用于编译期检查（如 `@Override`）。 |
| `RetentionPolicy.CLASS` | 保留至编译后的字节码 | 运行时不可见，JVM 加载类时会丢弃。**这是默认策略**。 |
| `RetentionPolicy.RUNTIME` | 保留至运行时 | 可通过反射 API 在运行时读取。常用于框架集成（如 Spring `@Autowired`）。 |

**示例：**

```java
// 运行时可通过反射读取该注解
@Retention(RetentionPolicy.RUNTIME)
public @interface RunImmediately { }
```

### 2.3  `@Inherited`

#### 2.3.1  作用

`@Inherited` 用于标注一个注解类型，使得**当这个注解修饰一个类时，它的所有子类会自动继承这个注解**。

#### 2.3.2  核心规则

- **仅对类继承有效**：只作用于 `@Target(ElementType.TYPE)` 的注解，即类、接口、枚举上的注解。对方法、字段等其他元素的注解**无效**。
- **会受到 `@Target` 限制**：如果 `@Target` 的参数不包含 `ElementType.TYPE`，那么该注解将失效。
- **仅沿类继承链向下传递**：子类会**继承**父类上的被 `@Inherited` 修饰的注解，但==接口的实现、方法的重写不会触发注解继承==。同时，只向下传递一层。也就是说，子类的子类不会继承到该注解。
- **反射查询时生效**：在子类上通过 `getAnnotation()` 方法可以查询到从父类继承来的注解。

### 2.4  `@Documented`

#### 2.4.1  作用

`@Documented` 是一个标记元注解，用于告诉 Javadoc 工具：**在生成 API 文档时，应当将被修饰的注解包含在文档中**。

#### 2.4.2  默认行为

- 默认情况下，Java 的 Javadoc 工具在生成 HTML 文档时，**不会**显示注解信息。
- 使用 `@Documented` 修饰自定义注解后，当该注解出现在某个类、方法或字段上时，生成的 Javadoc 页面中会**明确展示该注解**。

### 2.5  重复注解 `@Repeatable`

`@Repeatable` 是 Java 8 引入的一个**元注解**（即注解的注解），用于标记一个注解可以在同一个程序元素（如类、方法、字段）上**重复出现多次**。在没有这个特性之前，同一个元素上不能重复使用同一个注解，必须借助 " 容器注解 " 来包装多个值。

定义步骤

1. 注解本身用 `@Repeatable` 元注解修饰，并指定容器注解。
2. 提供对应的容器注解定义。它必须有一个 `value()` 方法，返回可重复注解的数组类型。

```java
// 可重复的注解
@Repeatable(Schedules.class)
@interface Schedule {
    String day();
}

// 容器注解
@interface Schedules {
    Schedule[] value();
}

// 使用
@Schedule(day = "Monday")
@Schedule(day = "Friday")
public class WeeklyTask { }
```

## 3  自定义注解语法

### 3.1  基本定义

使用 `@interface` 自定义注解时，自动继承了 `java.lang.annotation.Annotation` 接口，

```java
@Target(ElementType.TYPE)          // 作用目标
@Retention(RetentionPolicy.RUNTIME) // 生命周期
public @interface AnnotationName { // 通过 @interface 自定义注解
    // 注解元素（参数）声明
}
```

使用方式：

```java
@AnnotationName
public class MyClass { }
```

### 3.2  注解元素

注解内部可声明零个或多个**注解元素**（Annotation Element），语法以无参无异常方法声明。

```java
@Target(ElementType.TYPE)          // 作用目标
@Retention(RetentionPolicy.RUNTIME) // 生命周期
public @interface AnnotationName {
    // 注解元素（参数）声明
    数据类型 参数名(); // 必填元素
    数据类型 参数名() default 值; // 带默认值的参数
}
```

- 元素类型
	- 元素类型限定：**基本数据类型**、`String`、`Class`、枚举 (Enumeration)、注解 (Annotatioon)，以及上述类型的一维数组。
	- 不允许使用包装类型、集合类型或自定义引用类型。
- 参数名
	- 参数名可以是任意，但是对于单个参数，建议命名为 `value`
- 默认值
	- 不能有不确定的值。
	- 任何非基本类型的元素，无论是在定义还是使用注解时，都不能使用 null 作为其默认值。
	- 因此，可以自定义一些特殊的值，比如空字符或负数，用于表示该元素不存在。

### 3.3  使用

```java
// 单个参数的注解
@AnnotationName（参数名 = 值）
注解元素

// 单个参数 value
@AnnotationName（值）  // 等价于 @AnnotationName（value = 值）
注解元素

// 对于多个参数，以逗号隔开
@AnnotationName（参数名 = 值, 参数名 = 值, 参数名 = 值） 
注解元素
```

> **注意**：注解元素在语法上以方法形式定义，但在使用时表现为赋值语句。其底层实现为接口方法，反射调用时也通过方法名访问。
