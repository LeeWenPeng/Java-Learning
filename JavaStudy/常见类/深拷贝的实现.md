所谓的深拷贝

1. 对于基础类型、不可变类型、枚举类型，进行浅拷贝
2. 对于其他引用类型，创建一个新的引用，并将原始引用指向的数据，逐个拷贝到新引用指向的对象中

因此，深拷贝的步骤是：

1. 对对象进行浅拷贝
2. 判断对象的类型是否是需要深拷贝的类型
3. 如果需要深拷贝，则创建一个新的引用
4. 则逐个对对象内的字段重复进行深拷贝

## 1  拷贝构造函数

**定义**：提供一个构造器，参数为同类型对象，在内部手动复制每个字段。

    String name;
    private Date date;

    public Employee(String name, Date date) {
        this.name = name;
        this.date = date;
    }

// 拷贝构造
//    public Employee(Employee other) {

//    }

    public Employee(Employee other){
        this.name = other.getName();
        this.date = new Date(other.getDate()); // 提供了 Date 的深度拷贝构造
    }
           
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public Date getDate() {

        this.date = date;

## 2  递归重写 clone()

递归重写 clone 方法的本质是：**在每一层对象调用自身的 `super.clone()`（浅拷贝）获取独立外壳，然后通过递归调用修正该层内部的引用类型字段**。

因为所有的引用类型对象最终是由基础数据类型和不可变数据类型组成的。

**定义**：类实现 `Cloneable` 接口，重写 `clone()` 方法，并在其中递归调用所有可变引用字段的 `clone()`。

```java
package Object.CloneTest;

/**
 * @BelongsProject: untitled
 * @BelongsPackage: Object.CloneTest
 * @Author: Lee
 * @CreateTime: 2026-04-21 08:09
 * @Description: TODO
 * @Version: 1.0
 */
public class Address implements Cloneable{
    String city;

    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}

class Person implements Cloneable{
    String name;
    Address address;

    @Override
    protected Object clone() throws CloneNotSupportedException {
        Person cloned = (Person) super.clone();
        cloned.address = (Address) address.clone(); // 递归克隆可变引用
        return cloned;
    }
}
```

## 3  序列化与反序列化

**定义**：将对象写入字节流（或 JSON 字符串），再从中反序列化出新对象。

### 3.1  Java 原生序列化

要求被拷贝对象及其所有引用字段都实现 `Serializable` 接口：

```java
package Object.CloneTest;

import java.io.*;

public class Util {
    public static <T> T deepCopy(T obj) throws IOException, ClassNotFoundException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        ObjectOutputStream oos = new ObjectOutputStream(bos);
        oos.writeObject(obj);

        ByteArrayInputStream bis = new ByteArrayInputStream(bos.toByteArray());
        ObjectInputStream ois = new ObjectInputStream(bis);
        return (T) ois.readObject();
    }
}
```

### 3.2  JSON 序列化

不要求 `Serializable`，但要求有无参构造器，且序列化过程有格式转换开销

## 5  反射

```java
package Object.CloneTest;

import java.io.*;
import java.lang.reflect.Array;
import java.lang.reflect.Field;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Modifier;
import java.util.Collection;
import java.util.IdentityHashMap;
import java.util.Map;

/**
 * @BelongsProject: untitled
 * @BelongsPackage: Object.CloneTest
 * @Author: Lee
 * @CreateTime: 2026-04-21 08:20
 * @Description: TODO
 * @Version: 1.0
 */
public class Util {
    public static <T> T deepCopy(T obj) throws IOException, ClassNotFoundException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        ObjectOutputStream oos = new ObjectOutputStream(bos);
        oos.writeObject(obj);

        ByteArrayInputStream bis = new ByteArrayInputStream(bos.toByteArray());
        ObjectInputStream ois = new ObjectInputStream(bis);
        return (T) ois.readObject();
    }

    public static <T> T ReflectiondeepCopy(T obj) throws NoSuchMethodException, InvocationTargetException, InstantiationException, IllegalAccessException {
        if(obj == null) return null;

        // 缓存已经拷贝的对象，处理循环引用
        Map<Object, Object> cache = new IdentityHashMap<>();
        return deepCopyInternal(obj, cache);
    }

    @SuppressWarnings("unchecked")
    private static <T> T deepCopyInternal(T obj, Map<Object, Object> cache){
        if(obj == null) return null;

        Class<?> clazz = obj.getClass();

        // 1. 基础类型/不可变类型/枚举 - 浅拷贝：直接返回
        if(isImmutable(clazz)){
            return obj;
        }

        // 2. 循环引用
        if(cache.containsKey(obj)){ // 已经拷贝过的，直接返回副本
            return (T) cache.get(obj);
        }

        // 3. 数组类型特殊处理
        if(clazz.isArray()){
            return (T) copyArray(obj, cache);
        }

        // 4. 集合类 不处理
        if(Collection.class.isAssignableFrom(clazz)){
            throw new UnsupportedOperationException("集合类请使用序列化深拷贝");
        }

        // 5. 普通对象
        try {
	        // 拷贝对象：创建一个新的对象
            T copy = (T) clazz.getDeclaredConstructor().newInstance();
            cache.put(obj, copy);

            Field[] fields = clazz.getDeclaredFields();
            for(Field field : fields){
                if(Modifier.isStatic(field.getModifiers())){ // 静态字段跳过
                    continue;
                }

				// 拷贝成员
                field.setAccessible(true);
                Object fieldValue = field.get(obj); // 浅拷贝
                // 判断是否是引用类型：深拷贝
                if(fieldValue != null){
                    Class<?> fieldValueClass = fieldValue.getClass(); // 获取字段的类型
                    if(!isImmutable(fieldValueClass)){ // 判断数据类型
                        fieldValue = deepCopyInternal(fieldValue, cache);
                    }
                }
                
                field.set(copy, fieldValue);
            }
            return copy;
        } catch (Exception e){
            throw new RuntimeException("深度拷贝失败： " + clazz.getName(), e);
        }
    }

	// 复制数组
    private static Object copyArray(Object array, Map<Object, Object> cache){

	    // 拷贝数组对象 - 创建一个新的数组
        int len = Array.getLength(array);
        Class<?> componentType = array.getClass().getComponentType();
        Object copy = Array.newInstance(componentType, len);
        cache.put(array, copy); // 记录

		// 拷贝数组元素
        for(int i = 0; i < len; i++){
            Object element = Array.get(array, i);
            if(element != null && !isImmutable(componentType)){
	            // 引用类型 深拷贝
                element = deepCopyInternal(element, cache);
            }
            Array.set(copy, i, element);
        }
        return copy;
    }

	// 判断是不是基础数据类型以及不可变类型、枚举类型
	// 这些数据类型都不需要进行深拷贝
    private static boolean isImmutable(Class<?> clazz){
        return clazz.isPrimitive() ||
                clazz == String.class ||
                clazz == Integer.class ||
                clazz == Long.class ||
                clazz == Boolean.class ||
                clazz == Byte.class ||
                clazz == Short.class ||
                clazz == Double.class ||
                clazz == Float.class ||
                clazz == Character.class ||
                clazz.isEnum() ||
                clazz == java.math.BigDecimal.class ||
                clazz == java.math.BigInteger.class ||
                clazz == java.time.LocalDate.class ||
                clazz == java.time.LocalDateTime.class ||
                clazz == java.time.LocalTime.class ||
                clazz == java.util.UUID.class;
    }
}
```
