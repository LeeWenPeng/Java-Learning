## 1 题目

- 两个线程交替打印字母
- 顺序打印
- 一个线程打印大写字母
- 一个线程打印小写字母
- 目标输出：`AbCd…Yz`

## 2 代码

```java
package cn.msgcenter.test;

/**
 * @description: TODO
 * @author: Lee
 * @version: 1.0
 * @date: 2026-08-30 00:03
 */
public class AlternatePrinting {
    private static final Object lock = new Object();    // 锁
    private static char currentLetter = 'A';            // 资源
    private static boolean printUpperCase = true;       // 打印标志

    public static void main(String[] args) {
        Thread uppperCasePrinter = new Thread(() -> printLetters(true));
        Thread lowerCasePrinter = new Thread(() -> printLetters(false));

        uppperCasePrinter.start();
        lowerCasePrinter.start();
    }

    private static void printLetters(boolean isUpperCase){
        while(currentLetter <= 'Z'){
            synchronized (lock) {
                // 如果当前打印
                while(printUpperCase != isUpperCase){
                    try {
                        lock.wait();
                    }catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }

                if(currentLetter > 'Z') break; // 再次检查，防止被唤醒后超出

                // 打印
                char toPrint = isUpperCase ? currentLetter : Character.toLowerCase(currentLetter);
                System.out.println(toPrint);

                printUpperCase = !printUpperCase;   // 切换打印标志
                currentLetter++;                    // 递增

                lock.notifyAll();
            }
        }
    }
}
```
