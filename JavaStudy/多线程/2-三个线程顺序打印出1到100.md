## 1  思路

- 两个线程时，通过奇偶来控制打印
- 三个线程只能通过对 3 取余的余数来控制打印

## 2  代码

```java
public class AlterNatePrintingThreeThreads {
    private int currentNumber = 1;              // 当前要打印的数字，同时作为控制打印的标志
    private final Object lock = new Object();   // 锁对象

    public static void main(String[] args) {
        AlterNatePrintingThreeThreads apt = new AlterNatePrintingThreeThreads();

        // 3n+0
        Thread t0 = new Thread(() -> apt.printNumber(0));
        t0.start();

        // 3n+1
        Thread t1 = new Thread(() -> apt.printNumber(1));
        t1.start();

        // 3n+2
        Thread t2 = new Thread(() -> apt.printNumber(2));
        t2.start();

    }

    /**
     * 线程主体
     * @param flag 打印标志 0:3n+0 1:3n+1 2:3n+2
     */
    private void printNumber(int flag) {
        while(currentNumber <= 100) {
            synchronized (lock) {
                while(currentNumber % 3 != flag){
                    try {
                        lock.wait();
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }
                if(currentNumber <= 100 && currentNumber % 3 == flag){
                    System.out.println("Thread " + flag + " Print: " + currentNumber);
                    currentNumber++;
                    lock.notifyAll();
                }
            }
        }
    }
}
```
