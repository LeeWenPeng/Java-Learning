# Java到底是值传递还是引用传递？

## 1  什么是形参和实参？

- 形参：用于定义方法时使用的参数，用于接受调用者传递来的参数。
- 实参：调用时传递给方法的参数，传递前需要预先赋值。

## 2  什么是值传递和引用传递？

- 值传递：调用方法时，将实际参数拷贝一份副本传递给方法，这样在方法修改形式参数时，不会影响到实际参数。
- 引用传递：也叫地址传递，指在调用方法时，将实际参数的地址传递给方法，这样在方法中对形式参数的修改将影响到实际参数。

## 3  Java的参数传递机制

Java 严格遵循**值传递**原则，但是根据参数类型的不同，表现形式有差异

### 3.1  基本数据类型

- 传递的是值的拷贝
- 在方法内修改形参不会影响实参

### 3.2  引用数据类型（特殊的值传递）

- 传递的是引用地址的拷贝
- 当形参和实参指向同一个地址时，方法内可通过地址修改对象状态，但不会影响原引用指向
- 当形参和实参指向不同地址时，在方法内修改形参不会影响实参

### 3.3  String 数据类型（特殊的引用类型）

- 传递的是引用地址的拷贝
- String具有不变性，任何“修改”都将生成新对象，原引用不变

## 4  为什么Java中只有值传递？

为了保证内存安全和程序可预测性，避免C++中指针操作带来的复杂性和风险。
