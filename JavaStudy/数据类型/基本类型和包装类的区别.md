## 1  基础类型和包装类的区别

基础类型和包装类的区别主要由四条

### 1.1  一、包装类型可以为 null，基础类型不可以

由于包装类型可以为 null，而基础类型不可以。因此，包装类型可以用于 POJO。



> 为什么POJO 属性要使用包装类型？
>
> ---
>
> 因为数据库查询的结果可能是 null，如果使用基础类型的话，由于自动拆箱，会抛出 NullPointerException 异常。

### 1.2  二、包装类型可以用于泛型，而基础类型不可以

泛型使用基础类型会编译报错

```java
// List<int> list = new ArrayList<>(); // 报错
List<Integer> list = new ArrayList<>();
```

> 为什么泛型不能使用基础类型呢？
>
> ---
>
> 因为泛型在编译时会进行类型擦除，最后只保留原始类型，而原始类型只能是 Object 及其子类，而基本类型并不是 Object 的子类

### 1.3  三、基本类型比包装类型更高效

1. 基础类型是在栈中存储的具体数值；而包装类型是引用类型，其本身存储在堆区，而其实例对象的引用存储在栈区。显然，包装类型占用更多的内存空间。
1. 包装类使用时需要创建对象，频繁的装箱会造成不必要的内存消耗，影响性能

### 1.4  四、等值比较方式不同

- 基础类型的等值比较使用 `==` 运算符
- 包装类型对象的等值比较使用 `equals()` 方法
- 包装类型对象可以通过 `==` 判断是否为同一个对象。
