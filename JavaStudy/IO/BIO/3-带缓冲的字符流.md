## 1  概念

`BufferedReader`/`BufferedWriter` 为 Reader 和 Writer 增加了缓冲区的实现

### 1.1  装饰器模式的典型应用

- `FileReader` 提供基础的字符读取能力，每次 `read` 都会触发一次系统调用（或少量调用，取决于内部缓冲）。
- `BufferedReader` 将 `FileReader` 包装，内部维护一个字符数组（默认大小 8192 字符），当调用 `readLine()` 时，它会批量从底层流中预读数据填满内部缓冲，后续逐行提取便可直接从内存返回，极大减少磁盘 I/O 次数。
- `BufferedWriter` 同理，对 `FileWriter` 进行包装，累积多个写操作，待到缓冲区满或调用 `flush()/close()` 时才一次性写出，大幅提升写入效率。

## 2  重要方法

### 2.1  readLine

`BufferedReader.readLine()`

- **功能**：读取一行文本。一行的结束由换行符 `'\n'`、回车符 `'\r'` 或回车后紧跟换行符组成。
- **返回值**：返回包含该行内容的字符串（**不含行终止符**）；如果已到达文件末尾，则返回 `null`。
- **阻塞行为**：若内部缓冲区数据不足以确定下一行，该方法会从底层流进行阻塞式读取，直至读到换行符或流末尾。
- **内存管理**：返回的 `String` 对象每次都是新创建的，适合按行处理文本，如日志分析、配置文件读入。

### 2.2  write

```java
BufferedWriter.write(String s)
```

- 将字符串写入内部缓冲区，并不立即写入底层 `FileWriter`。可连续调用多次，性能比直接写 `FileWriter` 高。
- 注意：此方法不主动添加换行符，因此每次输出一行后需手动补充换行。

### 2.3  newLine

```java
BufferedWriter.newLine();
```

- **功能**：写入一个行分隔符。行分隔符由系统属性 `line.separator` 定义，在 Linux/Unix 下为 `"\n"`，在 Windows 下为 `"\r\n"`。
- **重要性**：保证生成的文件在不同操作系统间可被正确识别行边界。如果用硬编码的 `"\n"`，在 Windows 记事本中可能显示为一行。

## 3  示例：文件复制 - 字符缓冲

```java
package org.IO;

import java.io.*;

/**
 * @Description: 基于 BIO 的文件复制程序, 使用缓冲区, 按行读取
 */
public class BIO3_2 {
    public static void main(String[] args) {
        String filePath = "/home/leewenpeng/IdeaProjects/untitled/resources/";
        String fileName = "test";
        String nameAf = ".txt";
        
        // 1. 创建 Reader 和 Writer
        // 2. 根据 Reader 和 Writer 创建 BufferedReader 和 BufferedWriter
        try (FileReader fr = new FileReader(filePath + fileName + nameAf);
             FileWriter fw = new FileWriter(filePath + fileName + "_copy3" + nameAf);
             BufferedReader br = new BufferedReader(fr);
             BufferedWriter bw = new BufferedWriter(fw);){
            String line;
            while((line = br.readLine()) != null){
                // 每次读取一行，写入一行
                bw.write(line);
                bw.newLine();
            }
        } catch (FileNotFoundException e) {
            throw new RuntimeException(e);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```
