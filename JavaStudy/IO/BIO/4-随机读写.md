## 1  概念

`RandomAccessFile` 是 Java IO 中一个特殊的类，**不属于** `InputStream`/`OutputStream` 或 `Reader`/`Writer` 体系，它独立存在，允许对文件进行**随机读写**。其核心特性：

- **支持读取和写入**：通过构造器参数 `mode` 指定访问模式（如 `"r"` 只读、`"rw"` 读写）。
- **文件指针操作**：内部维护一个**文件指针**（file pointer），用于指示下一次读写操作的位置。可以通过 `seek(long pos)` 随意移动指针，实现任意位置的读写，而无需按顺序处理文件。
- **即支持字节也支持基本类型**：提供 `readByte()`、`readInt()`、`writeDouble()` 等方法，可以直接读写 Java 基本类型数据，而无需手工转换字节数组。
- **阻塞式 I/O**：与 BIO 模型一致，读写操作会阻塞直到数据就绪。

该类结合了字节流的随机访问能力和数据类型的便捷处理，常用于需要修改文件特定位置数据、读写记录文件（如数据库末端的索引）等场景。

### 1.1  什么时候使用

- 实际开发中，若复制整个文件且无需中间定位，使用 `FileInputStream/FileOutputStream` 更直接；
- 若需要从文件特定位置开始复制（如断点续传），`RandomAccessFile` 便可派上用场，通过 `seek` 跳过已传输部分。

## 2  重要函数详解

### 2.1  构造器

```java
RandomAccessFile(String name, String mode);
```

- **功能**：创建一个随机访问文件流，关联到指定文件路径。
- **模式参数**（mode）：
    - `"r"`：以**只读**方式打开。若文件不存在抛出 `FileNotFoundException`。
    - `"rw"`：以**读写**方式打开。若文件不存在则尝试创建；若存在，**不会清空原有数据**，文件指针初始位置为 0。
    - `"rws"`：同 `"rw"`，但每次写入都会将数据和元数据（如文件长度）**同步**写入底层存储设备，保证持久性，但性能较低。
    - `"rwd"`：同 `"rw"`，但仅每次写入的数据被同步，不强制更新元数据（减少磁盘操作）。
- **文件指针**：新创建的对象文件指针位于 0（文件开头）。
- **异常**：若文件不可访问或模式非法，抛出 `IllegalArgumentException` 或 `FileNotFoundException`。

### 2.2  read

```java
int read(byte[] b)
```

- **功能**：从当前文件指针位置开始，读取最多 `b.length` 个字节到数组 `b` 中。
- **返回**：实际读取的字节数；若已到达文件末尾则返回 `-1`。
- **指针变动**：读取成功后，文件指针自动向后移动 `实际读取字节数` 个位置，为下次读取或写入做好准备。
- **阻塞**：若数据不可用（如磁盘未就绪），方法会阻塞当前线程。
- **与 `FileInputStream.read(byte[])` 相同**：行为完全一致，只是底层由 `RandomAccessFile` 的文件指针管理。

### 2.3  write

```java
void write(byte[] b, int off, int len)
```

- **功能**：将数组 `b` 中从偏移量 `off` 开始的 `len` 个字节写入文件，从当前文件指针位置开始覆盖或追加。
- **指针变动**：写入后文件指针自动移动 `len` 个字节。
- **模式要求**：文件必须以可写模式打开（如 `"rw"`），否则抛出 `IOError`。
- **自动扩展**：如果写入位置超过当前文件长度，文件会自动扩展以容纳新数据，中间空缺部分将填充未定义内容（操作系统可能填 0）。
- **注意**：与输出流不同，`RandomAccessFile` 的 `write` 不会截断文件，而是在指针位置直接覆盖。

### 2.4  seek

```java
void seek(long pos)
```

- 将文件指针移动到指定绝对位置（从文件开头计算的字节偏移量）。可以在读写前调用此方法实现跳跃访问，例如从文件末尾读取元数据、修改中间某段数据。

```java
// 将指针定位到文件末尾
seek(length())
```

### 2.5  setLength

```java
void setLength(long newLength)
```

- 设置文件长度。可用于截断文件或预先分配空间。

```java
// 清空文件
setLength(0);
```

### 2.6  其他随机访问核心方法

- **`long getFilePointer()`**：返回当前文件指针的位置（字节偏移量），可用于保存位置以便后续恢复。
- **`long length()`**：返回文件的当前长度（字节数）。结合 `seek(length())` 可以将指针定位到文件末尾进行追加写入（但直接使用 `"rw"` 模式写入时指针已处于末尾，若先顺序写了数据指针便已推进）。
- **`int skipBytes(int n)`**：尝试将文件指针向后移动 `n` 字节，返回实际跳过的字节数。

## 3  示例：文件复制 - 随机访问

```java
package org.IO;

import java.io.File;
import java.io.FileNotFoundException;
import java.io.IOException;
import java.io.RandomAccessFile;

/**
 * @Description: 基于 BIO 的文件复制程序, 随机读写
 */
public class BIO3_3 {
    public static void main(String[] args) {
        String filePath = "/home/leewenpeng/IdeaProjects/untitled/resources/";
        String fileName = "test";
        String nameAf = ".txt";

        try (RandomAccessFile in = new RandomAccessFile(filePath + fileName + nameAf, "r");
            RandomAccessFile out = new RandomAccessFile(filePath + fileName + "_copy4" + nameAf, "rw")
        ) {
            byte[] buffer = new byte[1024];
            int hasRead;
            while ((hasRead = in.read(buffer)) != -1) {
                out.write(buffer, 0, hasRead);
            }
        } catch (FileNotFoundException e) {
            throw new RuntimeException(e);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```
