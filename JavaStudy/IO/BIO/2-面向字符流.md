## 1  概念

`Reader`/`Writer` 用于操作字符

### 1.1  和字节流的核心差异

- 缓冲区的数据类型不同
	- 字节流缓冲区类型为 `byte[]`
	- 字符流缓冲区类型为 `char[]`，每个元素占两个字节，存储 Unicode 码点
- 编码转换
	- `FileReader` 在读取时，会将读取到的字节数据解码为字符，按系统默认字符编码
	- `FileWriter` 在写入时，会将字符按默认编码重新编码为字节写入磁盘。
	- 因此，字符流只适合处理文本数据，处理二进制文件会损坏内容

### 1.2  本质

字符流本质是对字节流的装饰，因此阻塞特性、关闭特性和字节流一致。

## 2  重要方法

### 2.1  `FileReader` 构造器

```java
FileReader fread = new FileReader(String fileName)
```

- 底层是 `new FileInputStream(fileName)`，然后用 `InputStreamReader` 包装，使用平台默认字符集将字节流转为字符流。

```java
// 底层
FileReader fread = new InputStreamReader(new FileInputStream(fileName));
```

指定编码器

```java
// 指定编码器
FileReader fread = new InputStreamReader(InputStream in, String charsetName)

// 指定编码器为 `StandardCharsets.UTF_8)`
FileReader fread = new InputStreamReader(new FileInputStream(fileName), StandardCharsets.UTF_8)
```

### 2.2  `FileWriter` 构造器

```java
FileWriter(String fileName)
```

- 底层是 `new FileOutputStream(fileName)`，用 `OutputStreamWriter` 包装，同样使用默认编码。同样可用重载版本指定编码。

### 2.3  read

```java
fr.read(char[] cbuf)
```

- 从文件中读取字符并存入数组，返回实际读取的字符数，末尾返回 `-1`。
- 其内部会先读取字节，再解码。若文件使用非默认编码，此处可能产生乱码。(**编码不一致问题**)

### 2.4  write

```java
fw.write(char[] cbuf, int off, int len)
```

- 将指定范围的字符写入文件。在写入磁盘前会经编码器转为字节序列。

## 3  示例：文件复制 - 面向字符流

```java
package org.IO;

import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

/**
 * @Description: 基于 BIO 的文件复制程序,字符流
 */
public class BIO3_1 {
    public static void main(String[] args) {
	    // 文件路径
        String filePath = "/home/leewenpeng/IdeaProjects/untitled/resources/";
        String fileName = "test";
        String nameAf = ".txt";
        
        // 创建 Reader 和 Writer
        try(FileReader fr = new FileReader(filePath + fileName + nameAf);
            FileWriter fw = new FileWriter(filePath + fileName + "_copy2" + nameAf);){
            // 创建字符缓冲区
            char[] buffer = new char[1024];
            int hasRead;
            // Reader 通过 read 读
            while((hasRead = fr.read(buffer))!=-1){
	            // Writer 通过 write 写
                fw.write(buffer,hasRead);
            }

        } catch (FileNotFoundException e) {
            throw new RuntimeException(e);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```
