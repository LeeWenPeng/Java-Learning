## 1  BIO

面向流（字节流/字符流）编程的 I/O 方式

| 特性         | `FileInputStream`/<br>`FileOutputStream` | `FileReader`/<br>`FileWriter` | `RandomAccessFile`        |
| ---------- | ---------------------------------------- | ----------------------------- | ------------------------- |
| **数据单元**   | 字节                                       | 字符                            | 字节 + 基本类型                 |
| **访问方式**   | 顺序读写（单向）                                 | 顺序读写                          | **随机读写**（通过 seek 移动指针）    |
| **读写能力**   | 输入流只读，输出流只写                              | 同样单向                          | 通过模式自由组合读/写               |
| **文件打开行为** | 输出流默认清空或覆盖                               | 输出同样清空                        | `"rw"` 模式不会清空原有数据，可原地修改   |
| **编码支持**   | 无                                        | 默认系统编码                        | 无（读写字节，但可以手动编码）           |
| **适用场景**   | 流式传输、文件复制、二进制处理                          | 文本文件处理                        | 需要跳跃式读写、操作固定长度记录、修改文件中间部分 |
