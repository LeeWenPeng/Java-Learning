## 1  概念

`InputStream`/`OutputStream` 用于读写字节

## 2  重要方法

### 2.1  `FileInputStream` 构造器

```java
// 1
FileInputStream(String name);
// 2
File file = new File(String name);
FileInputStream(File file);
```

- 构造器 $1$：通过文件路径名创建输入流，打开与该文件的连接。如果文件不存在，抛出 `FileNotFoundException`。内部会获取一个文件描述符并与操作系统文件句柄关联。
- 构造器 $2$：通过 File 文件创建输入流。

### 2.2  `FileOutputStream` 构造器

```java
// 1
FileOutputStream(String name);
// 2
FileOutputStream(String name, boolean append);
```

- 通过路径名创建输出流。若文件不存在则创建；若已存在，默认会**清空原有内容**。
- 如果想要追加写入，则使用构造器 $2$，对形参 append 传入参数 `true`

### 2.3  read 函数

```java
fis.read(byte[] b);
```

- **功能**：从输入流中读取一定数量的字节，存入缓冲区数组 `b`。
- **返回值**：实际读入的字节数，作为 `int` 返回；若已读到文件末尾，返回 `-1`。
- **阻塞行为**：若流中当前无可读数据（例如磁盘读取未就绪），该方法会**阻塞当前线程**，直到有数据可用、流关闭或异常发生。

> [!note] 细节
> 它并不会保证填满整个数组，读取的字节数 `hasRead` 可能小于 `b.length`（尤其在文件剩余不足 1024 字节时）。因此写回时必须使用 `write(buffer, 0, hasRead)` 指定有效长度。

### 2.4  write 函数

```java
fos.write(byte[] b, int off, int len);
```

- **功能**：将字节数组 `b` 中从偏移量 `off` 开始的 `len` 个字节写入输出流。
- **阻塞行为**：写入操作同样可能阻塞，直到数据实际被刷写到磁盘（或内核缓冲区）才会返回。

> [!note]
> 若直接使用 `write(buffer)` 会写入整个数组，可能包含上一次残留的多余数据，造成目标文件多余脏数据。因此循环内必须采用带偏移量和长度的重载版本。

## 3  示例：文件复制 - 面向字节流

```java
package org.IO;

import java.io.*;

/**
 * @Description: 基于 BIO 的文件复制程序, 字节流
 */
public class BIO3 {
    public static void main(String[] args) {
	    // 路径 path
        String filePath = "/home/leewenpeng/IdeaProjects/untitled/resources/";
        String fileName = "test";
        String nameAf = ".txt";
        
        // 1. 创建字节输入流 FileInputStream 和 字节输出流 FileOutputStream
        try(FileInputStream fis = new FileInputStream(filePath + fileName + nameAf);
            FileOutputStream fos = new FileOutputStream(filePath + fileName + "_copy" + nameAf);){
            // 2. 创建字节缓冲区
            byte[] buffer = new byte[1024];
            // 3. 输入流 read 将文件内容读取到 buffer
            int hasRead;
            while((hasRead = fis.read(buffer)) > 0){
	            // 4. 输出流 write 将 buffer 中内容写入到目标文件内
                fos.write(buffer, 0, hasRead);
            }
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```
