- Protobuf：是 Google 公司内部的混合语言数据标准，是一种轻便、高效的结构化数据存储格式，可以用于结构化数据序列化，支持 Java、Python、C++、Go 等语言。
- Thrift：apache 开源项目，是一个点对点的 RPC 实现。
- Hessian：动态类型、二进制、紧凑的，并且可跨语言移植的一种序列化框架。
	- RPC 框架 Dubbo 就支持 Thrift 和 Hession。
- Kryo：是用于 Java 的快速高效的二进制对象图序列化框架。Kryo 还可以执行自动的深拷贝和浅拷贝。 这是从对象到对象的直接复制，而不是从对象到字节的复制。
- FST：是一个 Java 实现二进制序列化库。
