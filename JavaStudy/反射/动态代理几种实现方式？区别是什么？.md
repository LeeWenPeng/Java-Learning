## 1  JDK 动态代理

- 优点：
	- JDK 原生支持，无须引入第三方库，简单可靠
	- 平滑进行 JDK 版本升级，而字节码库通常需要进行更新，以保证在新版 Java 上能够使用
	- 代码实现较为简单
- 缺点：必须基于接口，无法直接代理一个没有实现任何接口的普通类

## 2  CGLIB

- 优点
	- 基于继承，而非是接口。面对不便于实现接口的调用目标时，更合适
	- 只操作我们关心的类，而不会影响其他类
	- 调用性能高，适合高频调用场景
- 缺点：基于继承实现，无法代理 `final` 类和 `final` 方法

## 3  字节码库 (Byte Buddy)

- 优点
	- 性能卓越，在某些场景下优于 CGLIB 和 JDK 动态代理
	- API 设计现代、类型安全，功能强大且灵活，是现代框架的首选
- 缺点
	- 需要引入额外的依赖，保持更新以适应更新版的 JDK
	- 学习难度大
