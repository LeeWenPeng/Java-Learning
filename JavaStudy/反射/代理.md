## 1 静态代理

代理模式：为其他对象提供一种代理，以控制对这个对象的访问

案例

```java
package org.Reflection;

// 代理类
public class StaticProxy extends Subject{
    private Subject obj;
    @Override
    public void request() {
        if(obj == null){
            obj = new SubjectReality();
        }

        obj.request();
    }
}

// 接口
abstract class Subject{
    public abstract void request();
}

// 业务类
class SubjectReality extends Subject {
    @Override
    public void request() {
        System.out.println("SubjectReality");
    }
}
```

优点

- 分离业务的实现和调用
- 增强业务功能

缺点

- 大量使用静态代理，会使类的规模增大，不易维护
- 由于代理类和业务类本质上就是一种类，代理类只有中介作用，这使得系统结构比较臃肿和松散

## 2 动态代理

- 动态代理是一种代理机制，是代理模式和装饰器模式的应用
- 动态代理可以让调用者和实现者之间解耦

## 3 JDK Proxy

### 3.1 理论

#### 3.1.1 代理类生成过程

当调用 `Proxy.newProxyInstance` 时，内部执行步骤为：

1. 检查参数合法性：接口非空无重复、类加载器有效等
2. 查找或生成代理类
	1. 代理类会被缓存
	2. 缓存未命中，则生成字节码
3. 定义并加载代理类：使用传入的 `loader` 将字节码转换为 `Class` 对象
4. 获取构造函数
5. 创建代理实例：通过反射调用构造函数，返回代理对象

#### 3.1.2 方法调用拦截流程

当代理类调用接口方法时

1. JVM 执行代理类中的接口方法
2. 该方法内部调用 `super.h.invoke(this, m1, null)`。`h` 是 `newProxyInstance` 传入的第三个参数。
3. `h` 中的 invoke 函数被触发，执行自定义逻辑，并通过 `method.invoke(obj, args)` 调用真实对象的对应方法
4. 最终将返回值返回给调用方

### 3.2 方法和接口

#### 3.2.1 newProxyInstance

````java
```java
public static Object newProxyInstance(ClassLoader loader,
                                      Class<?>[] interfaces,
                                      InvocationHandler h)
    throws IllegalArgumentException
````

- 参数
    - `ClassLoader loader`：类加载器。负责**定义并加载**动态生成的代理类的字节码。通常为目标对象的类加载器，或者是上下文类加载器。
        - `obj.getClass().getClassLoader()`
    - `Class<?>[] interfaces`：接口列表。指定动态生成的代理类要实现的接口列表。代理对象在运行时，会被强制转换为其中一种接口类型，并且可以调用这些接口中声明的所有方法。
        - `obj.getClass().getInterfaces()`
    - `InvocationHandler h`：调用处理器。动态代理核心逻辑载体。当代理对象上的任何方法被调用时，调用都会被拦截并转发到该处理器的 `invoke` 方法中。
- 返回值：一个动态生成的代理对象，其类型是运行时生成的 `$proxyX` 类实例，且该类实现了 interfaces 参数中指定的所有接口
- **异常**：如果传入的类加载器无法访问任一接口、接口列表重复、接口非 public 且不在同一包下等，会抛出 `IllegalArgumentException` 或其他运行时异常。

#### 3.2.2 InvocationHandler 接口

```java
public interface InvocationHandler {
    public Object invoke(Object proxy, Method method, Object[] args)
        throws Throwable;
}
```

- 参数
    - `Object proxy`：当前代理对象实例
    - `Method method`：被调用的接口方法中的 `Method` 对象。
    - `Object[] args`：调用方法时，传递的参数数组。如果方法无参，则为 `null`

```java
package org.Reflection;

import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

public class MyDynamicProxy {
    public static void main(String[] args) {
        HelloImpl hlp = new HelloImpl();
        MyInvocationHandler mih = new MyInvocationHandler(hlp);

        // 构造代理方法
        Hello proxyH = (Hello) Proxy.newProxyInstance(HelloImpl.class.getClassLoader(), HelloImpl.class.getInterfaces(), mih);
        // 调用代理方法
        proxyH.sayHello();
    }

}
Proxy
// 代理目标
interface Hello {
    void sayHello();
}

class HelloImpl implements Hello{
    @Override
    public void sayHello() {
        System.out.println("Hello World!");
    }
}

// invoke
class MyInvocationHandler implements InvocationHandler {
    private Object target; // 实例对象

    public MyInvocationHandler(Object target) {
        this.target = target;
    }

    @Override
    public Object invoke(Object o, Method method, Object[] args) throws Throwable {
        System.out.println("Invoking sayHello");
        Object res = method.invoke(target, args);
        return res;
    }
}
```
