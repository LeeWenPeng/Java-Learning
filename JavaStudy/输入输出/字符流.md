## 字符流

字符流有两个顶级父类，二者都是抽象类

- Reader
- Writer

## 字符输出流Writer

### 方法

- append()：向流中追加文本
- write()：向流中写文本
- flush()：刷新缓冲区
- close()：关闭流

### FileWriter

- FileWriter是Writer的子类，用于关联一个文件
- 它是一个输出节点流，通过该流可以将程序中的文本写到指定文件中 



使用步骤

```java
// 1. 创建一个流
FileWriter fileWriter  = new FileWriter("Path");
// 2. 写入数据
fileWriter.write("xxx");
// 3. 关闭流
fileWriter.close();
```

## 字符输入流Reader

- 是 Writer 的子类，被称为打印流
- 它的方法，除了重写的 Writer 的方法外，还增加了格式化和 println 方法
