## 抽象类和抽象方法

### 抽象方法

抽象方法是被 abstract 修饰的方法



抽象方法只有方法的声明，而没有方法的实现，也就是仅包含方法名、参数列表和返回类型，而没有方法体。



```java
public abstract returnType funcName(args...);
```



- 抽象方法允许的访问修饰符 public(默认)、protected

- 抽象方法不允许的修饰符：private、final、static、navite

### 抽象类

包含抽象方法的类叫做抽象类，同样通过 abstract 修饰符修饰，不能实例化。



抽象类的目的主要是代码重用。



抽象类的特点

- 抽象类不能实例化
- 和普通类一样，允许各种形式的成员
- 抽象类中可以有一个或多个抽象方法，也可以没有抽象方法。
- 通过 extends 使用抽象类
- 一个类只能继承一个抽象类



当一个类继承抽象类时

- 如果该类需要实例化，那么该类必须要实现抽象类中所有的抽象方法。
- 否则，该类需要用 abstract 修饰为新的抽象类。



当重写抽象方法时，建议使用注解 `@override`。

## 接口

接口通过关键字 interface 创建，一般使用 public 访问修饰符修饰，否则只有在接口相同的包内才能使用该接口。



接口中包含三种方法（Java 8之后，Java 8 之前仅包含抽象方法）

- 抽象方法
- 默认方法
- 静态方法



接口中的方法默认为 public，无论你是否使用 public 访问修饰符进行修饰。



接口可以包含属性，但这些属性被隐式指定为 `static final` 类型



通过 implements 关键字，可以使一个类实现某个接口。



可以通过 extends 关键字对接口进行扩展，增加新的方法声明，或组合多个接口等。

- 当组合接口时，如果两个接口之间具有同名的方法，且两个方法无法构成重载，这时就会编译报错。



当一个类同时进行继承和实现时，需要先写 extends，之后再写 implements，多个接口之间使用`,`隔开



```java
public class A{
    // ...
}

public interface B{
    // ...
}
public interface C{
    // ...
}

public class D extends A implements B, C{
    // ...
}
```

### 接口嵌套

接口可以嵌套在类或接口中



当接口嵌套在一个类中时，该接口的访问修饰符可以是 private

- 但只有定义在该类内部的内部类才能实现该接口，而且该内部类将无法向上转型。
- 可以将 private 的接口作为返回类型，但返回的值将无法被使用（因为是类的私有成员类型）



当接口嵌套在一个接口中时，嵌套接口的访问修饰符自动为 public。因为接口内部成员必须是 public 的。



## 接口和设计模式

### 策略设计模式

### 适配器模式

接口适配：当一个类用一个接口作为传入的参数时，那么实现了该接口的新类，同样也可以作为该类的传入参数。（里氏替换）



### 工厂方法设计模式

用于生成符合某个接口的对象

```java
package interfaces;

interface Game{
    boolean move();
}

interface GameFactory{
    Game getGame();
}

class Checkers implements Game{
    private int moves = 0;
    private static final int MOVES = 3;

    @Override
    public boolean move() {
        System.out.println("Checkers move " + moves);
        return ++moves != MOVES;
    }
}

class CheckersFactory implements GameFactory{
    @Override
    public Game getGame() {
        return new Checkers();
    }
}

class Chess implements Game{
    private int moves = 0;
    private static final int MOVES = 4;

    @Override
    public boolean move() {
        System.out.println("Chess move " + moves);
        return ++moves != MOVES;
    }
}

class ChessFactory implements GameFactory{
    @Override
    public Game getGame() {
        return new Chess();
    }
}

public class Games {
    public static void playGame(GameFactory gameFactory) {
        Game g = gameFactory.getGame();
        while(g.move()){
            // todo ...
            ;
        }
    }

    static void main() {
        playGame(new CheckersFactory());
        playGame(new ChessFactory());
    }
}
```
